Why “molt”

Crabs grow by shedding their shell, which is called molting. Rust’s mascot is a crab, and in molt the range of what you understand is your shell: it widens the more you use molt.

Getting started

  1. molt doctor

    Checks what the endpoint and each model support, and records it.

  2. molt init

    Asks about the Rust you have written, and saves your profile after you confirm it.

  3. molt

    In a cargo project, type a request at molt>.

How it works

molt works on two lines. The main line writes the code. When a write needs an item your profile does not have as known, molt writes it as a small step (at most 3 such items and 30 changed lines), stops right after it, and opens a side line.

Main line · molt>

  1. You type a request
  2. What you know is written in bulk, without stopping
  3. An item you have not written becomes a small step, and molt stops at the boundary
  4. After cargo check passes, molt commits only when you approve

Side line · molt [sub: items]>

  1. Shows the lines of the step and explains them
  2. Shows the same part written within your profile
  3. Answers as many questions as you like; they never enter the main line
  4. You choose one of ① to ④

① Understood

The step stays, the items become known, and molt uses them from now on.

② Write it without them

molt takes the step back and writes that part without the items.

③ Write it myself

molt takes the step back and shows where to write what. Type /done, and molt checks and reviews your lines.

④ Next

The step stays. The next step that uses the items stops again, with a shorter explanation.

Screens

Nemotron on Nebius Token Factory

molt sends each request to one of three roles, so that a request goes to a model of the size it needs. The defaults are NVIDIA Nemotron 3 models on Nebius Token Factory, and molt doctor checks what each of them supports before molt relies on it.

light

Judges the answers of molt init into your profile, and writes the one-line policy after ②.

generate

Writes the code through tools, the rewrite of ②, the review of ③, and the commit message.

reason

Explains a step, writes the same part within your profile, guides ③, and answers on the side line.

The default models and how to change them: README.

Install

molt runs cargo check in your project, so it needs the Rust toolchain (rustup). Built binaries for macOS (Apple silicon) and Linux (x86_64) are on the release page. Following the README, put molt on your PATH and set the API key in NEBIUS_API_KEY, then:

molt doctor
molt init

The README also has the download commands, what to do when macOS Gatekeeper stops molt, and how to build from source.
